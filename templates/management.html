🐙 GitHub Settings

▾

A Personal Access Token (PAT) is required to clone and poll private repositories. Public repos work without one.

  1. Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Click Generate new token, give it a name like "AutoRun"
  3. Under Repository access, select the repos AutoRun should access
  4. Under Permissions → Repository → Contents, set to Read-only
  5. Generate and paste the token below

The token is stored in autorun.yaml and is never sent to the browser after saving.
